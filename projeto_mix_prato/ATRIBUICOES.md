# Fontes e atribuições

As fotos de exemplo e as anotações de ingredientes pertencem ao conjunto Nutrition5k, criado por Google Research e colaboradores, licenciado sob Creative Commons Attribution 4.0. São utilizadas aqui apenas como demonstração do projeto.

Thames, Q., Karpur, A., Norris, W., Xia, F., Panait, L., Weyand, T., e Sim, J. “Nutrition5k: Towards Automatic Nutritional Understanding of Generic Food.” CVPR 2021. https://github.com/google-research-datasets/Nutrition5k

O primeiro modelo experimental incluído foi treinado para este projeto com ferramentas de código aberto e o conjunto Nutrition5k. O projeto usa bibliotecas Python externas, cada qual sujeita à sua própria licença.
